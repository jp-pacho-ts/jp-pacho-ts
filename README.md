## 01 ─ 自己紹介
### THE PERSON BEHIND THE BUILD.

I’m **John Philip “JP” Pacho**, a Full-Stack Software Engineer and UI/UX designer based in **Tacloban City, Philippines**.

My background bridges **Electrical Engineering and Information Technology**. Currently pursuing my **Master of Science in Information Technology**, I build applications with attention to both the systems underneath and the people using them.

**My work spans** reporting platforms, digital libraries, role-based dashboards, and brand websites.
